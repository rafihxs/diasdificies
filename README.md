# Além dos Dias Difíceis

Jogo narrativo criado por Rafihx para Gaby.

## Executar
Abra `index.html` em um servidor local ou publique a pasta no GitHub Pages.

Exemplo com Python:
```bash
python -m http.server 8000
```
Depois acesse `http://localhost:8000`.

## Controles
- WASD ou setas: movimentar
- Espaço ou Enter: interagir
- Celular: controles na tela

## Publicar no GitHub Pages
1. Crie um repositório.
2. Envie todo o conteúdo desta pasta para a raiz.
3. Vá em Settings > Pages.
4. Selecione a branch principal e a pasta raiz.
5. Salve.

O jogo usa `localStorage` para salvamento automático.
